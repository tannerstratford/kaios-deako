Install Deako Lights

Open this page in the phone browser, then follow the two steps. This stages the installer and jumps to the System page, exactly like the OStore installer.

Step 1 — stage

Ready.

Step 2 — on the blank System page

Type these two commands into the address bar, in order, in the same tab:

javascript:document.createElement('script') javascript:document.write(name)

A black status bar shows the result. INSTALL OK means it worked. INSTALL FAILED shows the exact reason — copy that text back.

Before it will work

The light controller must be running on your home machine, and the phone on the same Wi-Fi. Start it with:

cd ~/deako-app && ~/.deako-venv/bin/python app.py

The app defaults to 192.168.1.60:8099. If that machine's IP changes, set the new one in the app: right soft key > Controller address.
